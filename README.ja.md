# Spam filtering（スパム情報フィルタリング）

> 🌍 [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [English](README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Português](README.pt.md) · [Русский](README.ru.md)

ブラウジングをクリーンに保ちます。**Spam filtering** は、アクセスするページからスパム、ポップアップ、バナー、トラッカーなどのジャンクコンテンツを自動的に除去します。すべてローカルで実行され、プライバシーを保護します。

## 主な特長

- スパム・ジャンクコンテンツをブロック：ポップアップ、バナー、トラッカー、解析スクリプト
- 自分専用のプレーンテキストルール——いつでもインポート・編集・エクスポート
- 信頼できるサイトをワンクリックでホワイトリスト登録
- ブロック統計（今日 / 累計）
- 10 言語対応
- 100% ローカル・プライベート——アカウント不要、クラウドなし、データ収集なし
- システムレベルで動作——ブラウザ拡張機能は不要

## システム要件

- Windows 10 / 11

## はじめに

1. Releases ページから最新インストーラーをダウンロードします。
2. インストールして起動します。
3. 設定で「システムプロキシを引き継ぐ」をオンにします。
4. 通常どおりブラウジング——ジャンクは自動的にフィルタリングされます。

## ルールの編集

ルールはプレーンテキストで保存され、1 行に 1 件です。アプリの「ルール」ページで追加するか、ルールファイルをインポートします。

### ルールの形式

| 例 | 意味 |
| --- | --- |
| `\|\|example.com^` | ドメインとそのすべてのサブドメインをブロック |
| `\|\|example.com/path/page^` | 特定のアドレス（ドメイン + パス）をブロック |
| `example.com` | このテキストを含むアドレスをブロック |
| `@@\|\|good.example.com^` | 例外——このドメインは常に許可 |
| `0.0.0.0 ad.example.com` | hosts 形式のエントリ |
| `! コメント` / `# コメント` | コメント行。この文字で始まる行は無視 |

### ヒント

- `||` はドメインの先頭にルールを固定します。`^` は「ドメインまたはパスの末尾」（区切り文字）を意味します。
- シンプルに始める：`||ドメイン^` で大半のケースをカバーできます。必要に応じて `||www.example.com/ads/banner^` のようなパスルールを追加します。
- ルール保存後、ブロック統計で動作を確認できます。

### HTTPS について

既定では、HTTPS リクエストは**ドメイン名のみ**で照合されます（完全なアドレスは暗号化されており見えません）。**完全なアドレス（パスを含む）**で照合するには、設定で「HTTPS 復号化（MITM）」をオンにし、プロンプトに従ってルート証明書をインストールし（一度だけ）、ブラウザを再起動します。以後、`||www.example.com/ads/banner^` のようなパスルールが HTTPS サイトでも有効になります。

## 動作原理（概要）

- アプリはローカルプロキシを実行し、システムプロキシを引き継ぐことで、ブラウザのトラフィックがここを経由します。
- 各リクエストはルールと照合され、一致したものはブロック、それ以外はそのまま転送されます。
- すべてのフィルタリングはローカルで行われます——データはどこにもアップロードされません。

## トラブルシューティング

**インターネットに接続できない？** 最も可能性が高い原因は、アプリが異常終了し、システムプロキシが無効なポートを指したまま残っていることです。

- **解決策 1：アプリを再起動する。** 起動時に残っているプロキシ設定を自動検出してクリーンアップします。
- **解決策 2：プロキシを手動でオフにする。** Windows 設定 → ネットワークとインターネット → プロキシ → 「プロキシサーバーを使用する」をオフにします。
- 通常、アプリの終了（トレイ → 終了）でプロキシは自動的に元に戻ります。残るのは異常終了（クラッシュ、強制終了、停電）の場合のみです。

## プライバシー

Spam filtering はローカルツールです。すべてのフィルタリングはお使いのデバイス上で行われます——ブラウジングデータがデバイスの外に出ることはありません。
