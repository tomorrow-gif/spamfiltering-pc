# Spam filtering (фильтрация нежелательной информации)

> 🌍 [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [English](README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Português](README.pt.md) · [Русский](README.ru.md)

Сохраняйте чистоту при просмотре веб-страниц. **Spam filtering** автоматически удаляет спам, всплывающие окна, баннеры, трекеры и другой нежелательный контент с посещаемых страниц — всё выполняется локально и конфиденциально на вашем устройстве.

## Основные возможности

- Блокирует спам и нежелательный контент: всплывающие окна, баннеры, трекеры, аналитические скрипты
- Собственные правила в виде обычного текста — импорт, редактирование и экспорт в любое время
- Белый список доверенных сайтов в один клик
- Статистика блокировок (сегодня / всего)
- Поддержка 10 языков
- 100% локально и конфиденциально — без аккаунта, без облака, без сбора данных
- Работает на уровне системы — расширение браузера не требуется

## Системные требования

- Windows 10 / 11

## Начало работы

1. Загрузите последнюю версию установщика со страницы Releases.
2. Установите и запустите приложение.
3. Включите **Использовать системный прокси** в настройках.
4. Просматривайте сайты как обычно — нежелательный контент фильтруется автоматически.

## Редактирование правил

Правила хранятся в виде обычного текста, по одному правилу в строке. Добавляйте правила на странице **Правила** в приложении или импортируйте файл правил.

### Форматы правил

| Пример | Значение |
| --- | --- |
| `\|\|example.com^` | Заблокировать домен и все его поддомены |
| `\|\|example.com/path/page^` | Заблокировать конкретный адрес (домен + путь) |
| `example.com` | Заблокировать любой адрес, содержащий этот текст |
| `@@\|\|good.example.com^` | Исключение — всегда разрешать этот домен |
| `0.0.0.0 ad.example.com` | Запись в формате hosts |
| `! комментарий` / `# комментарий` | Строки комментариев — строки, начинающиеся с этих символов, игнорируются |

### Советы

- `||` привязывает правило к началу домена; `^` означает «конец домена или пути» (разделитель).
- Начните с простого: `||домен^` покрывает большинство случаев. Добавляйте правила пути только при необходимости, например `||www.example.com/ads/banner^`.
- После сохранения правила проверьте статистику блокировок, чтобы убедиться, что оно работает.

### О HTTPS

По умолчанию HTTPS-запросы сопоставляются только по **имени домена** (полный адрес зашифрован и не виден). Для сопоставления по **полному адресу, включая путь**, включите **Расшифровку HTTPS (MITM)** в настройках, установите корневой сертификат по запросу (только один раз) и перезапустите браузер. После этого правила пути, такие как `||www.example.com/ads/banner^`, будут действовать и на HTTPS-сайтах.

## Как это работает (кратко)

- Приложение запускает локальный прокси и может перехватывать системный прокси, чтобы трафик браузера проходил через него.
- Каждый запрос проверяется по вашим правилам: совпадения блокируются, всё остальное передаётся без изменений.
- Вся фильтрация выполняется на вашем устройстве — ничего никуда не загружается.

## Устранение неполадок

**Нет доступа в интернет?** Наиболее вероятная причина: приложение было закрыто неожиданно и оставило системный прокси, указывающий на недействительный порт.

- **Решение 1 — перезапустите приложение.** При запуске оно автоматически обнаруживает и очищает остаточные настройки прокси.
- **Решение 2 — отключите прокси вручную.** Параметры Windows → Сеть и Интернет → Прокси → отключите «Использовать прокси-сервер».
- Обычно выход из приложения (значок в трее → Выход) автоматически восстанавливает прокси. Остатки возникают только после аварийного завершения (сбой, принудительное завершение, отключение питания).

## Конфиденциальность

Spam filtering — это локальный инструмент. Вся фильтрация выполняется на вашем устройстве — ваши данные просмотра никогда не покидают ваш компьютер.
