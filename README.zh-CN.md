# Spam filtering（垃圾信息过滤）

> 🌍 [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [English](README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Português](README.pt.md) · [Русский](README.ru.md)

保持浏览干净。**Spam filtering** 自动屏蔽网页中的垃圾信息、弹窗、横幅、追踪器和其它干扰内容——全部在本地运行，保护隐私。

## 功能亮点

- 屏蔽垃圾信息：弹窗、横幅、追踪器、统计脚本
- 自定义纯文本规则——随时导入、编辑、导出
- 一键白名单信任网站
- 拦截统计（今日 / 累计）
- 支持 10 种语言
- 100% 本地运行、保护隐私——无账号、无云端、不收集数据
- 系统级生效——无需浏览器扩展

## 系统要求

- Windows 10 / 11

## 快速开始

1. 在 Releases 页面下载最新安装包。
2. 安装并启动应用。
3. 在设置中打开「接管系统代理」。
4. 正常浏览——垃圾信息自动过滤。

## 编辑规则

规则以纯文本保存，每行一条。在应用「规则」页面添加，或导入规则文件。

### 规则格式

| 示例 | 含义 |
| --- | --- |
| `\|\|example.com^` | 屏蔽该域名及其所有子域名 |
| `\|\|example.com/path/page^` | 屏蔽指定地址（域名 + 路径） |
| `example.com` | 屏蔽包含此文本的任何地址 |
| `@@\|\|good.example.com^` | 例外——始终放行该域名 |
| `0.0.0.0 ad.example.com` | hosts 格式条目 |
| `! 注释` / `# 注释` | 注释行，以这些字符开头将被忽略 |

### 提示

- `||` 将规则锚定到域名开头；`^` 表示「域名或路径的结尾」（分隔符）。
- 从简单开始：`||域名^` 可覆盖大多数情况；需要时再加路径规则，如 `||www.example.com/ads/banner^`。
- 保存规则后，可通过拦截统计确认是否生效。

### 关于 HTTPS

默认情况下，HTTPS 请求仅按**域名**匹配（完整地址已加密，无法看到）。若要按**完整地址（含路径）**匹配，请在设置中打开「HTTPS 解密（MITM）」，按提示安装根证书（仅一次），然后重启浏览器。此后 `||www.example.com/ads/banner^` 这类路径规则对 HTTPS 网站同样生效。

## 实现原理（简述）

- 应用运行本地代理，可接管系统代理，浏览器流量经此流转。
- 每个请求都会与你的规则比对：匹配的拦截，其余原样转发。
- 所有过滤均在本地完成——数据不上传。

## 常见问题

**无法上网？** 最可能的原因：应用被异常关闭，系统代理残留指向已失效端口。

- **方案一：重启应用。** 启动时会自动检测并清理残留的代理设置。
- **方案二：手动关闭代理。** 打开 Windows 设置 → 网络和 Internet → 代理 → 关闭「使用代理服务器」。
- 正常情况下，退出应用（托盘 → 退出）会自动还原代理；仅异常退出（崩溃、强制结束、断电）会残留。

## 隐私

Spam filtering 是本地工具。所有过滤都在你的设备上完成——浏览数据不会离开你的电脑。
