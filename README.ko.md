# Spam filtering（스팸 정보 필터링）

> 🌍 [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [English](README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Português](README.pt.md) · [Русский](README.ru.md)

깔끔한 브라우징을 유지하세요. **Spam filtering**은 방문하는 페이지에서 스팸, 팝업, 배너, 트래커 등 정크 콘텐츠를 자동으로 제거합니다 — 모든 것이 기기에서 로컬로 실행되며 개인정보를 보호합니다.

## 주요 기능

- 스팸 및 정크 콘텐츠 차단: 팝업, 배너, 트래커, 분석 스크립트
- 나만의 일반 텍스트 규칙 — 언제든 가져오기, 편집, 내보내기
- 신뢰하는 사이트를 원클릭으로 화이트리스트 등록
- 차단 통계 (오늘 / 전체)
- 10개 언어 지원
- 100% 로컬 및 프라이빗 — 계정 없음, 클라우드 없음, 데이터 수집 없음
- 시스템 수준에서 동작 — 브라우저 확장 프로그램 불필요

## 시스템 요구 사항

- Windows 10 / 11

## 시작하기

1. Releases 페이지에서 최신 설치 프로그램을 다운로드합니다.
2. 설치하고 앱을 실행합니다.
3. 설정에서 **시스템 프록시 사용**을 켭니다.
4. 평소처럼 브라우징 — 정크 콘텐츠가 자동으로 필터링됩니다.

## 규칙 편집

규칙은 일반 텍스트로 저장되며 한 줄에 하나입니다. 앱의 **규칙** 페이지에서 추가하거나 규칙 파일을 가져옵니다.

### 규칙 형식

| 예시 | 의미 |
| --- | --- |
| `\|\|example.com^` | 도메인과 모든 하위 도메인 차단 |
| `\|\|example.com/path/page^` | 특정 주소(도메인 + 경로) 차단 |
| `example.com` | 이 텍스트를 포함하는 모든 주소 차단 |
| `@@\|\|good.example.com^` | 예외 — 이 도메인은 항상 허용 |
| `0.0.0.0 ad.example.com` | hosts 형식 항목 |
| `! 주석` / `# 주석` | 주석 줄 — 이 문자로 시작하는 줄은 무시 |

### 팁

- `||`은 규칙을 도메인 시작 부분에 고정합니다. `^`는 "도메인 또는 경로의 끝"(구분자)을 의미합니다.
- 간단하게 시작하세요: `||도메인^`으로 대부분을 처리할 수 있습니다. 필요할 때 `||www.example.com/ads/banner^` 같은 경로 규칙을 추가합니다.
- 규칙 저장 후 차단 통계로 작동 여부를 확인할 수 있습니다.

### HTTPS 정보

기본적으로 HTTPS 요청은 **도메인 이름으로만** 일치합니다(전체 주소는 암호화되어 볼 수 없음). **전체 주소(경로 포함)**로 일치하려면 설정에서 **HTTPS 복호화(MITM)**를 켜고 안내에 따라 루트 인증서를 설치한 다음(한 번만), 브라우저를 다시 시작하세요. 이후 `||www.example.com/ads/banner^` 같은 경로 규칙이 HTTPS 사이트에서도 적용됩니다.

## 동작 원리 (요약)

- 앱은 로컬 프록시를 실행하고 시스템 프록시를 인계받아 브라우저 트래픽이 이곳을 거쳐 갑니다.
- 모든 요청이 규칙과 대조됩니다: 일치하면 차단, 나머지는 그대로 전달됩니다.
- 모든 필터링은 기기에서 수행됩니다 — 어떤 데이터도 업로드되지 않습니다.

## 문제 해결

**인터넷에 접속할 수 없나요?** 가장 흔한 원인은 앱이 비정상 종료되어 시스템 프록시가 유효하지 않은 포트를 가리키며 남아 있는 것입니다.

- **해결 1: 앱을 다시 시작하세요.** 시작 시 남아 있는 프록시 설정을 자동으로 감지해 정리합니다.
- **해결 2: 프록시를 수동으로 끄세요.** Windows 설정 → 네트워크 및 인터넷 → 프록시 → "프록시 서버 사용"을 끕니다.
- 일반적으로 앱 종료(트레이 → 종료) 시 프록시는 자동으로 복원됩니다. 잔여물은 비정상 종료(크래시, 강제 종료, 정전) 시에만 남습니다.

## 개인정보

Spam filtering은 로컬 도구입니다. 모든 필터링은 사용자 기기에서 이루어집니다 — 브라우징 데이터가 기기를 떠나지 않습니다.
