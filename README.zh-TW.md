# Spam filtering（垃圾資訊過濾）

> 🌍 [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [English](README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Português](README.pt.md) · [Русский](README.ru.md)

保持瀏覽乾淨。**Spam filtering** 會自動遮蔽網頁中的垃圾資訊、彈窗、橫幅、追蹤器及其他干擾內容——全部在本機執行，保護隱私。

## 功能亮點

- 遮蔽垃圾資訊：彈窗、橫幅、追蹤器、統計腳本
- 自訂純文字規則——隨時匯入、編輯、匯出
- 一鍵白名單信任網站
- 攔截統計（今日 / 累計）
- 支援 10 種語言
- 100% 本機執行、保護隱私——無帳號、無雲端、不收集資料
- 系統層級生效——無需瀏覽器擴充功能

## 系統需求

- Windows 10 / 11

## 快速開始

1. 在 Releases 頁面下載最新安裝檔。
2. 安裝並啟動應用程式。
3. 在設定中開啟「接管系統代理」。
4. 正常瀏覽——垃圾資訊自動過濾。

## 編輯規則

規則以純文字儲存，每行一條。在應用程式「規則」頁面新增，或匯入規則檔。

### 規則格式

| 範例 | 含義 |
| --- | --- |
| `\|\|example.com^` | 遮蔽該網域及其所有子網域 |
| `\|\|example.com/path/page^` | 遮蔽指定位址（網域 + 路徑） |
| `example.com` | 遮蔽包含此文字的任何位址 |
| `@@\|\|good.example.com^` | 例外——始終放行該網域 |
| `0.0.0.0 ad.example.com` | hosts 格式條目 |
| `! 註解` / `# 註解` | 註解行，以這些字元開頭將被忽略 |

### 提示

- `||` 將規則錨定到網域開頭；`^` 表示「網域或路徑的結尾」（分隔符號）。
- 從簡單開始：`||網域^` 可涵蓋大多數情況；需要時再加入路徑規則，如 `||www.example.com/ads/banner^`。
- 儲存規則後，可透過攔截統計確認是否生效。

### 關於 HTTPS

預設情況下，HTTPS 要求僅按**網域**比對（完整位址已加密，無法看到）。若要按**完整位址（含路徑）**比對，請在設定中開啟「HTTPS 解密（MITM）」，依提示安裝根憑證（僅一次），然後重新啟動瀏覽器。此後 `||www.example.com/ads/banner^` 這類路徑規則對 HTTPS 網站同樣生效。

## 實作原理（簡述）

- 應用程式執行本機代理，可接管系統代理，瀏覽器流量經此流轉。
- 每個要求都會與你的規則比對：符合的攔截，其餘原樣轉發。
- 所有過濾均在本機完成——資料不上傳。

## 常見問題

**無法上網？** 最可能的原因：應用程式被異常關閉，系統代理殘留指向已失效的連接埠。

- **方案一：重新啟動應用程式。** 啟動時會自動偵測並清理殘留的代理設定。
- **方案二：手動關閉代理。** 開啟 Windows 設定 → 網路和網際網路 → 代理 → 關閉「使用 Proxy 伺服器」。
- 正常情況下，結束應用程式（系統匣 → 結束）會自動還原代理；僅異常結束（當機、強制終止、斷電）會殘留。

## 隱私

Spam filtering 是本機工具。所有過濾都在你的裝置上完成——瀏覽資料不會離開你的電腦。
